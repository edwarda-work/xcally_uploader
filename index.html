Bulk Compaigns

Split one contact file into agent lists and replace the lists in their existing campaigns.

Existing campaigns are matched by agent username. Previous lists are detached and remain in Contacts Manager.

1. Choose your contact file

Include a column such as AGENT_NAME with agent usernames or full names. Contacts are grouped by agent, regardless of row order.

2. Review the segments

Names are trimmed and grouped exactly as written. Agent accounts will be matched before creation.

Choose a CSV to preview its agents and contact counts.

3. Queue campaigns

Each agent’s new list replaces all contact lists currently linked to their existing campaign. Campaign names follow MARKET_AGENT_QUEUE_USERNAME, for example GH_AGENT_QUEUE_ZEINABE.

Leave both blank to use server credentials or the credentials entered in the Upload tab.

Agent assignments and calling settings are retained. Active campaigns are briefly paused during the list swap and resumed after verification. If a swap fails, check its reported status before resuming.
